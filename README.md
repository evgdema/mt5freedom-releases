# MT5Freedom — релизы

Здесь лежат готовые сборки MT5Freedom: приложение для Mac и Windows (пульт, Agent и советник внутри) и Agent для
Linux. Код — в отдельном закрытом репозитории. Приложение само проверяет этот репозиторий и предлагает обновление.

Последняя версия: [Releases → Latest](https://github.com/evgdema/mt5freedom-releases/releases/latest).

## Что скачать

| Компьютер | Файл |
| --- | --- |
| Mac с процессором Apple (M1, M2, M3, M4…) | `MT5Freedom_X.Y.Z_aarch64.dmg` |
| Mac с процессором Intel | `MT5Freedom_X.Y.Z_x64.dmg` |
| Windows 10/11 | `MT5Freedom_X.Y.Z_x64-setup.exe` |
| Linux-сервер (VPS) | `mt5freedom-linux-vps.sh` (сам скачает `mt5freedom-agent-x86_64-unknown-linux-gnu` и `MT5Freedom.ex5`) |

Какой у Mac процессор: меню  → «Об этом Mac», строка «Чип» (Apple M…) или «Процессор» (Intel).

Файлы `.app.tar.gz`, `.sig` и `latest.json` нужны обновлятору, скачивать их не надо.

## Почему система предупреждает

Приложение не подписано платным сертификатом Apple или Microsoft, поэтому macOS и Windows говорят, что не могут
проверить разработчика. Это ожидаемо. На Mac обход нужен один раз, при первом запуске; на Windows предупреждение
показывается при каждом запуске скачанного установщика, а установленное приложение запускается уже без него.
Обновления из самого приложения ставятся без предупреждений — их подлинность проверяется собственной подписью
MT5Freedom.

## Установка на Mac

Так это выглядит в macOS 26 (Tahoe), в macOS 15 (Sequoia) — так же или почти так же; в скобках — надписи в
английской macOS.

1. Откройте скачанный `.dmg` и перетащите значок MT5Freedom на папку «Программы» (Applications) — по стрелке в окне.
2. Запустите MT5Freedom из «Программ». macOS покажет окно «Не удалось открыть «MT5Freedom»» («“MT5Freedom” Not
   Opened») с двумя кнопками. **Синяя кнопка по умолчанию — «Переместить в Корзину» (Move to Trash): не нажимайте
   Enter.** Нажмите мышью «Готово» (Done).
3. Откройте меню  → «Системные настройки» → «Конфиденциальность и безопасность» (Privacy & Security) и прокрутите
   вниз до раздела «Безопасность» (Security). Там строка «Программа «MT5Freedom» заблокирована для защиты Mac»
   («“MT5Freedom” was blocked to protect your Mac») — нажмите рядом «Открыть всё равно» (Open Anyway).
4. Сразу появится второе окно «Открыть «MT5Freedom»?» («Open “MT5Freedom”?») с тремя кнопками. Синяя здесь тоже
   «Переместить в Корзину» — нажмите «Открыть всё равно» (Open Anyway).
5. macOS попросит имя и пароль администратора этого Mac (или Touch ID) — введите и нажмите «ОК». MT5Freedom
   запустится и откроет мастер установки. Дальше приложение запускается как обычно, без вопросов.

В macOS 14 (Sonoma) и старше проще: в «Программах» щёлкните MT5Freedom правой кнопкой (или с Control) → «Открыть» и в
окне подтвердите «Открыть». Если такой кнопки нет — путь через «Конфиденциальность и безопасность», как выше, а после
«Открыть всё равно» запустите приложение ещё раз и нажмите «Открыть».

Если macOS пишет «Программа повреждена и не может быть открыта» и кнопки «Всё равно открыть» нет, снимите метку
карантина в Терминале (Программы → Утилиты → Терминал):

```sh
xattr -dr com.apple.quarantine /Applications/MT5Freedom.app
```

и запустите приложение снова.

### MetaTrader 5 на Mac

MT5Freedom работает с MetaTrader 5 вашего брокера, его ставят отдельно (официальный установщик MetaQuotes для Mac
или установщик брокера), лучше до MT5Freedom:

- установщик MetaTrader 5 просит пароль администратора Mac — без него MT5 не установится;
- на Mac с процессором Apple нужна Rosetta: MetaTrader 5 для Mac собран для Intel. Обычно macOS сама предлагает
  установить Rosetta при первом запуске MT5 — согласитесь. Если не предложила и MT5 не открывается, поставьте её в
  Терминале (тоже с паролем администратора):
  ```sh
  softwareupdate --install-rosetta --agree-to-license
  ```

Запустите MT5 и войдите в счёт брокера, затем запустите MT5Freedom и пройдите мастер установки.

## Установка на Windows

В скобках — надписи в английской Windows.

1. Браузер может предупредить, что файл «скачивают редко». В Edge: «…» у загрузки → «Сохранить» (Keep) →
   «Показать больше» (Show more) → «Всё равно сохранить» (Keep anyway). В Chrome: «Сохранить» / «Всё равно скачать».
2. Запустите `MT5Freedom_X.Y.Z_x64-setup.exe`. Появится синее окно «Система Windows защитила ваш компьютер»
   (Windows protected your PC; это SmartScreen) — нажмите «Подробнее» (More info), затем «Выполнить в любом случае»
   (Run anyway). Окно появляется при каждом запуске скачанного файла, не только при первом.
3. Пройдите установщик. Установленный MT5Freedom запускается из меню «Пуск» уже без предупреждений.

Если кнопки «Выполнить в любом случае» нет, щёлкните по скачанному файлу правой кнопкой → «Свойства» → внизу вкладки
«Общие» отметьте «Разблокировать» → «ОК» и запустите снова.

## Windows-сервер (VPS)

На Windows-VPS ставится тот же `MT5Freedom_X.Y.Z_x64-setup.exe`, что и на обычный Windows-компьютер; пульт на Mac
или другом ПК подключается к нему через Tailscale. Публичных портов открывать не нужно.

1. Установите Tailscale на VPS и на компьютер с пультом ([tailscale.com/download](https://tailscale.com/download))
   и войдите в обоих в одну учётную запись. Адрес VPS в Tailscale — вида `100.x.y.z`.
2. На VPS установите MetaTrader 5 брокера и войдите в счёт, затем MT5Freedom (как в «Установке на Windows»). В мастере
   выберите «На этой машине», а на последнем шаге поставьте галочку «Разрешить подключение пульта по Tailscale».
3. Мастер покажет адрес Agent (`http://100.x.y.z:9200`) и кнопку «Выдать токен сейчас». Скопируйте токен — он
   показывается один раз. Адреса и галочка есть и потом, в разделе «Робот» → «Agent».
4. На компьютере с пультом: «Добавить установку…» → «Подключиться к серверу», адрес и токен.
5. Только если пульт не подключается: Tailscale обычно сам разрешает вход в брандмауэре Windows, но если при первом
   запуске Agent закрыть окно «Разрешить доступ», Windows запретит ему вход. Тогда выполните команду для брандмауэра,
   которую показывает мастер, в PowerShell от имени администратора: она снимает запрет и пускает к Agent только
   адреса Tailscale.

Agent и MT5 запускаются при входе пользователя в Windows: после перезагрузки VPS войдите в систему по RDP или
настройте автовход Windows.

## Обновление

Новую версию приложение предлагает само: плашка «Доступна версия X» → «Обновить и перезапустить». Робот при этом
не удаляется, советник продолжает торговать. Если на Windows вы запускаете новый установщик вручную поверх старой
версии, выберите «Do not uninstall» (не «Uninstall before installing»): удаление старой версии снимает робота с машины,
вернуть его можно мастером установки в «Настройках».

## Linux-сервер (VPS)

На Linux-VPS (Ubuntu 24.04, x86_64) MetaTrader 5 работает под Wine на виртуальном экране, а Agent и советник ставит
скрипт `mt5freedom-linux-vps.sh` из релиза. Пульт на Mac или Windows подключается к серверу через Tailscale;
публичных портов, кроме SSH, не нужно.

1. Установите Tailscale на VPS и на компьютер с пультом ([tailscale.com/download](https://tailscale.com/download)),
   войдите в одну сеть. Адрес VPS — `tailscale ip -4` (вида `100.x.y.z`).
2. Поставьте Wine (скрипт MetaQuotes `mt5linux.sh` с mql5.com ставит Wine и MT5 в префикс `~/.mt5`; можно и
   `winehq-stable` с [winehq.org](https://wiki.winehq.org/Ubuntu)).
3. Запустите скрипт тем пользователем, под которым будет работать MT5 (по SSH, root тоже подходит):
   ```sh
   curl -fsSLO https://github.com/evgdema/mt5freedom-releases/releases/latest/download/mt5freedom-linux-vps.sh
   bash mt5freedom-linux-vps.sh --firewall
   ```
   Он ставит Agent и советник в `~/.local/lib/mt5freedom`, виртуальный экран (Xvfb `:99`) и Agent в автозапуск systemd
   (работают после перезагрузки без входа в систему), открывает API Agent для Tailscale и с `--firewall` включает ufw:
   снаружи остаётся только SSH, порт 9200 — только через Tailscale.
4. Если MT5 ещё не установлен: `DISPLAY=:99 WINEPREFIX=~/.mt5 wine mt5setup.exe`. Чтобы увидеть экран сервера,
   запустите на VPS `bash mt5freedom-linux-vps.sh vnc`, а на своём компьютере `ssh -L 5900:127.0.0.1:5900 <пользователь>@<VPS>`
   и VNC-клиент на `localhost:5900` (на Mac — `open vnc://localhost:5900`). В MT5 войдите в счёт и добавьте
   `127.0.0.1` в «Сервис → Настройки → Советники → Разрешить WebRequest для следующих URL», затем закройте MT5.
5. Запустите скрипт ещё раз, с именем устройства пульта:
   ```sh
   bash mt5freedom-linux-vps.sh --token mac
   ```
   Он выберет найденный MT5, положит в него советник, запустит Terminal и покажет DeviceToken (один раз).
6. В пульте: «Добавить установку…» → «Подключиться к серверу», адрес `http://100.x.y.z:9200` и токен.

Обновление — тот же скрипт: `bash mt5freedom-linux-vps.sh` (последняя версия) или `--version X.Y.Z`. Если у робота есть
открытые позиции, советник обновляется из пульта кнопкой «Обновить советник» (или скриптом с `--confirm`). Отозвать
доступ пульта: `~/.local/lib/mt5freedom/mt5freedom-agent token revoke mac`. Журнал Agent:
`~/.local/share/mt5freedom/agent.log`.
